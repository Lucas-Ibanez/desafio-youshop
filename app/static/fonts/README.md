# Fontes do painel (Vincula)

Servidas localmente para o painel funcionar sem internet na demo (docs/BRAND.md, seções 3 e 8.2).
Baixadas da API do Google Fonts em 24/11/2026, só o subconjunto **latin** (U+0000-00FF e
pontuação, o que cobre á, ã, ç, é, õ e as aspas curvas).

| Arquivo | Família | Eixos |
|---|---|---|
| `SchibstedGrotesk-Variable.woff2` | Schibsted Grotesk | peso 400–900 |
| `Newsreader-Italic-Variable.woff2` | Newsreader itálico | peso 200–800, `opsz` 6–72 |
| `IBMPlexMono-Regular.woff2` | IBM Plex Mono | 400 |
| `IBMPlexMono-Medium.woff2` | IBM Plex Mono | 500 |

Licença: as três famílias são distribuídas sob a SIL Open Font License 1.1
