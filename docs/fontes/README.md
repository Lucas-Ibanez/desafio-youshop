# Fontes

Coloque aqui o guia do MVP (guia-mvp.md) e as validações H1–H4.

Estes arquivos ficam **fora do git** (decisão D13): eles têm nomes reais de anunciantes e de pessoas,
com vereditos de irregularidade. O `.gitignore` ignora tudo nesta pasta, exceto este README.
Cada pessoa que clonar o repositório precisa copiar as fontes para cá.
